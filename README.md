# Muse 数字人口播制作 Skill

用 [Muse](https://muse.ai) 自身的多模态能力（生图 / 生视频 / 语音）加 Remotion 包装，端到端生产数字人口播短视频的一套**实测版**制作规范：不是设想稿，而是把开源项目的功能逐项用 Muse 重做、逐项验收、把结论（含失败结论）逐条回写成的活文档。

## 血统

- 上游：开源项目 [digital-human-koubo](https://github.com/andyhuo520/digital-human-koubo)（作者 andyhuo520），其全量功能拆解为 F01–F29。
- 本 skill 把 F01–F29 逐项改为「只用 Muse 实现」的路线并全部实测收口；与原版的主要区别：不依赖外部生成工具的多工具链，生成、配音、对齐、包装、质检全在 Muse 侧闭环。
- 结构与随附流程图（八阶段、十九步、三道关卡、六条纪律）一一对应。

## 本体速览（SKILL.md）

- **流派前置**：先定流派坐标（节奏派 / 质感派 / 解说派 / 网感派），再选 A–E 五种风格，包装参数有出处地取值。
- **形象确认门**：主播图与首帧先经确认才投产；persona 文件含语速、代词等字段。
- **脚本四列**：台词 + 词锚拍点 + 表情 + 形态；段长按实测语速切分（中位 3.62 字/秒）。
- **三道质检 Gate**：渲染前静帧、成片抽帧（含段尾双查、嘴部逐秒密查、形态序列查）、切口连续性。
- **包装引擎**：五种风格 A–E 全部实测定版（A 自建引擎含数据三件套 LineDraw / BarCompare / DocFocus 与版式多样化纪律）。
- **配音工具包双档**：本地 CosyVoice3 零样本克隆（克隆主播本人音色为配音版首选）+ 云端 MiMo TTS（快速档）；另有离线三音色兜底。
- **口型同步全路线收口（2026-11-06）**：音频先行（无主播形态）定版；后期对齐三法（重剪 / 匀速拉伸 / 分句锚点拉伸）实测后整体否决；Wav2Lip 整片否决；MuseTalk 跑通待裁决。总对照与优缺点见 SKILL.md §9.8–§9.10。
- **故障排查表**（附录 C）：六十余条「症状 → 根因 → 修法」，全部来自真实生产事故。
